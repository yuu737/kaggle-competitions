# RSNA Knee Abnormality Detection — 402 / 6,300（上位6.4%、メダル確定待ち）

[大会ページ](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection)

## 課題

膝のMRI（DICOM、全体で約570GB）から、複数の異常（関節炎、滑膜炎、ベーカー嚢腫など）の有無を予測する医用画像の大会です。

## やったこと

### 1. 順位表の構造を調べる

公開順位表を全件取得すると、0.958に1,000以上のチームが並んでいた。公開ノートブック約25本の中身を調べると、名前は違っても、4つの出所のモデルの組み合わせでしかなかった。同じスコアの塊の中の順位は運に近いので、塊から離れる方法を考えた。

### 2. 自作モデル：弱いモデルを組み合わせる

2段階の疑似ラベル学習でモデルを作った。

1. 学習データを4つに分けて交差検証で学習し、各検査について「学習に使っていないモデルによる予測」（out-of-fold）を作る。
2. その予測を補正して元のラベルと混ぜ、新しいラベルとして ConvNeXt-S と ConvNeXt-T を学び直させる。混ぜる比率は0.5と0.7の両方を試し、比率は効く要素ではないことも確かめた。

1本ずつは弱くても、組み合わせると強くなった（正解の確かな58件での macro AUC）。

| モデル | AUC |
| --- | ---: |
| 2段目のモデル 1本 | 約0.913 |
| **2段目の4本と1段目の4本、計8本の組み合わせ** | **0.918** |
| 初期の自作 ConvNeXt-T ／ EffNetV2-S | 0.903 ／ 0.907 |
| **その2本の組み合わせ** | **0.914** |

提出での結果：

| 提出 | 中身 | 非公開 | 公開 |
| --- | --- | ---: | ---: |
| 自作モデルだけ（8本） | 単体では弱い | 0.919 | 0.930 |
| **最終提出 B** | 自作モデルを35%混ぜた | **0.943** | **0.958** |
| 最終提出 A | 系統の違う既存モデルの組み合わせ | 0.943 | 0.958 |

自作モデルは単体では0.930と弱いのに、35%という大きな比率で混ぜても、最上位の提出と同じスコアになった。予測の癖が違うので、ほかのチームの提出から一番離れた1本になり、最終2本の賭け方を分けるのに使えた。ただし、最上位を超えたわけではない。初期の自作2本を2割混ぜたときは、公開スコアが0.958から0.955に下がった例もある。

### 3. 系統の違うモデルを組み合わせる

塊の大半が使っていない系統のモデル（外部データを使わない ConvNeXt、単体0.950）を2割混ぜると、表示スコアは同じ0.958のまま、同じスコアの中の順位が1,092位から222位に上がった。最終2本は、系統の違うモデルを組み合わせた A と、自作モデルを混ぜた B に分け、非公開の順位の運を分散させた。

### 4. 試して効かなかったこと：ショウジョウバエの全脳コネクトーム

オスのショウジョウバエの中枢神経全体の配線図（[MaleCNS v1.0](https://male-cns.janelia.org/download/)、約20万の神経、2,600万本の接続）をすべて使い、MRIの画像特徴を全神経に入力して、配線に沿って信号を4回伝え、最後の神経の活動から12種類の異常を予測させた。

- 配線を迂回する／接続をシャッフルする／接続をゼロにする、という比較対照を同じ条件で用意し、配線が本当に予測に効いているかを比べた。
- 神経の種類ごとに信号の強さを学習できるよう改修し（約1万2千の群）、疎行列での逆伝播を実装した。視覚系のモデル [FlyVis](https://www.nature.com/articles/s41586-024-07939-3)（約4.6万神経）を再現し（誤差 2.2×10⁻⁶）、その知見を全脳モデルに移した。
- 結果：58件での macro AUC は0.620で、通常の分類器（0.605）とほぼ同じ。配線を迂回した版（0.627）と比べても、配線が効いている証拠は得られなかった。公開モデルに5%加えた提出も0.950→0.949で、改善しなかった。インターネットなしのKaggle上での推論までは完成させた。

## コード

- [`modal/train_student.py`](modal/train_student.py): 疑似ラベルで CoAtNet（352px）を学習するスクリプト。クラウドGPUの [Modal](https://modal.com/) で実行した。ラベルは「公開モデルの軟ラベル」と「自分の4分割OOF予測を補正したもの」を半分ずつ混ぜた
- [`scripts/prepare_public_labels.py`](scripts/prepare_public_labels.py)、[`make_stage2.py`](scripts/make_stage2.py): ラベルと2段目の入力の準備
- 全脳コネクトームの実験: [`trainable_wholebrain.py`](scripts/trainable_wholebrain.py)、[`train_wholebrain_adaptive.py`](scripts/train_wholebrain_adaptive.py)、[`flyvis_wholebrain_prior.py`](scripts/flyvis_wholebrain_prior.py) ほか。結果は [`reports/`](reports/)

## Claude Codeの使い方

Claude Codeで進めた。Kaggle APIで順位表の全件、上位11本のノートブック、議論110件を集めさせて分析と計画づくりに使い（[計画書](reports/PLAN_V2_20261019.md)）、学習・推論・提出の実装を任せた。どのモデルを作り、どう組み合わせ、最終2本をどう分けるかは自分で判断した。
